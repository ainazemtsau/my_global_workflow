# Правка к разделу «ЖДЁТ ТЕБЯ»

Раздел ты уже сделал. Здесь две неправды. Обе сегодня не видны — таких данных
пока нет, — но соврут при первом же появлении. Пишем только в `panel/**`.

## 1. Подписи чисел — по группам, а не по кучам

Сейчас в `renderWaiting` число подписано `нужно имя N` для всего нижнего списка.
А в нём две разные группы. Появится закрытая без причины — панель скажет про неё
«нужно имя», и это ложь.

Считай и подписывай по группам, показывай только ненулевые:

| группы | подпись |
|---|---|
| `decision` + `question` + `owner_call` | `ждёт ответа N` |
| `stalled` | `стоит N` |
| `unnamed_goal` | `нужно имя N` |
| `closed_unnamed` | `закрыто без причины N` |

## 2. «СТОИТ» не ждёт владельца — это ошибка в моём прежнем наряде

Наряд со статусом `blocked`/`waiting`/`paused` вовсе не обязательно стоит на
ВЛАДЕЛЬЦЕ: он может стоять на исполнителе, на сборке, на чём угодно. Условие
снятия лежит свободным текстом в `unblock_when`, и вычислить по нему «это на
владельце» НЕЛЬЗЯ. Значит панель не имеет права решать за него.

- в `WAITING_GROUPS` у `stalled` признак блокирующей меняется на `False`,
  то есть группа уезжает из `blocking` в `other`;
- в строку раздела добавь поле `unblock`: значение `unblock_when` из шапки, а
  если там нет — из блока тела тем же способом, что берутся остальные значения;
  нет нигде — `null`;
- на экране, если `unblock` не пуст, добавь в строку `div.waitline` с текстом
  `ждёт: <условие>`. Класс `waitline` уже есть в `style.css`, новых не заводи.

Так владелец сам видит, на нём это или нет, а панель ничего за него не решает.
