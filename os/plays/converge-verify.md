# Play: converge-verify

Purpose: a SEPARATE refutation session that tries to BREAK either a converged build spec before shape, or the exact owner-approved artifact that exhausts a parked specification outcome before review. A self-check cannot catch the assumption its author never saw; G5 requires the fresh session. No gate is weakened.

Reads: TREE.md, CHARTER.md, knowledge/ checklists/canon; for build, closed `work/converge-<node>.md`; for `outcome_kind: specification`, the exact versioned artifact and owner-approval receipt; plus this node's prior `converge-verify` verdicts. It does NOT read deciding-session reasoning.
Writes: NOW.md (decisions, open_calls — a finding bounces a row), LOG.md. Never writes knowledge/. Never answers a question; it only refutes or passes.

Precondition: either converge done (plus converge-arch when required), or a parked specification node has its exact artifact and owner words. Reached via `to: session, play: converge-verify`; never the authoring/work/day chat.

## Steps

1. **Recite the claim** — build attacks: (1) the question set is complete; (2) no answer leans on an unresolved question. Specification attacks: (1) every atomic done_when clause is satisfied by the exact artifact; (2) no required claim rests on an unresolved assumption. Name `verify_target: build|specification`.

2. **Attack completeness with an INDEPENDENT oracle.** Split compound done_when clauses atomically and map each to a build §WHAT row or specification-artifact section. Do not rely only on sources the author used. Apply the node-class decision checklist plus compete precedents. If none exists, author one from first principles before attack and propose it as canon; an empty oracle BLOCKS. An uncovered clause/class FAILS: name it, never fill it.

3. **Attack smuggling.** For each weight-bearing build line/acceptance or specification claim required by done_when, name every supporting value/fact and require a resolved citation or frozen canon id. Untraceable means FAIL. For an imported counterpart contract, re-derive the edge from this node before reading the counterpart, then diff. Build only: move leaked HOW magnitude/format to `→ PLAN`. Specification review never repairs, chooses content, or treats executor words as owner approval.

4. **Close.** Count this node's prior FAILs and name `round: <n>` (G3 ceiling: two). Round-1 FAIL: build returns named rows to converge[-arch], specification to its owner-authority `work`; verification reruns. Round-2 FAIL ENDS the paper phase — return nothing, issue no repair CALL, freeze the surface as evidence, and write ONE owner decision (G7): cut, split in `map`, or shape now with the open rows named as stubs. Recommend cut when the findings attack lines the previous repair itself wrote; that loop is generative, not converging. Only the owner's words open a third round. PASS writes `§SIGNOFF: converge-verify passed @ <date>` and play_check `verify_target: ... complete=PASS smuggling=PASS`. Build opens shape with acceptance/contracts to copy and PLAN-agenda. Specification opens narrow review with exact node, artifact identity, owner receipt and this later verification receipt; it never opens shape.

## Done when
Both attacks fail to find a hole within the ceiling; signoff exists; build hands evidence to shape, specification to review — or the ceiling is reached and one owner decision replaces the third round.

## Notes
- State the guarantee honestly: cited openings are structurally excluded; this independent oracle attacks uncited assumptions. Rigorous, not a closed proof.
- Decision-class checklists are cross-node canon (knowledge/, read_by converge-verify of that node-class); review/pulse promote them.
- No new owner G7 point below the ceiling: verify routes findings and decides nothing; at the ceiling it raises the owner's choice without picking it. Same finding twice → KERNEL two-strikes.
