# Play: converge-verify

Purpose: a SEPARATE refutation session that tries to BREAK either a converged build spec before shape, or the exact owner-approved artifact that exhausts a parked specification outcome before review. A self-check cannot catch the assumption its author never saw (G5). No G1–G10 gate is weakened; it no longer demands an answer to every question.

Reads: the node card, CHARTER.md, knowledge/ checklists/canon; for build, closed `work/converge-<node>.md`; for `outcome_kind: specification`, the exact versioned artifact and owner-approval receipt. It does NOT read deciding-session reasoning.
Writes: decision and call cards (below the ceiling a finding bounces a row) and journals. Never writes knowledge/. Never answers a question; it only refutes or passes.

Precondition: either converge done (plus converge-arch when required), or a parked specification node has its exact artifact and owner words. Reached via `to: session, play: converge-verify`; never the authoring/work/day chat.

## Steps

1. **Recite the claim** — build attacks: (1) every done_when clause reaches a row, answered or named `open`; (2) every `answered` row rests on a source outside the deciding leg. Specification attacks: (1) every atomic done_when clause is satisfied by the exact artifact; (2) no required claim rests on an unresolved assumption. Name `verify_target: build|specification`.

2. **Attack completeness against his own text.** Split compound done_when clauses atomically and map each to a build §WHAT row or specification-artifact section. Apply a node-class decision checklist ONLY when `knowledge/` already holds one as canon; a checklist this leg would write is a `capture`, never a standard and never a finding. A clause reaching NO row FAILS: name it, never fill it. A named `open` row covers its clause: an unanswered question is not a hole. Then name at least one done_when noun or charter lens the card never asks about — naming none is itself the finding.

3. **Attack smuggling.** For each weight-bearing build line/acceptance or specification claim required by done_when, name every supporting value/fact and require a resolved citation or frozen canon id. Build: an `answered` row whose only source is the deciding leg's own reasoning is named as such, and its repair is DEMOTION to `open` with an answerer named — never a fresh answer. Untraceable elsewhere means FAIL. For an imported counterpart contract, re-derive the edge from this node before reading the counterpart, then diff. Build only: move leaked HOW magnitude/format to `→ PLAN`. Specification review never repairs, chooses content, or treats executor words as owner approval.

4. **Close.** FAIL: build returns named rows to converge[-arch]; specification returns findings to its owner-authority `work`; verification reruns. A node's SECOND FAIL (count them in `history/`) ends its paper phase instead — return nothing, freeze the surface as evidence, and write ONE owner decision (G7): cut, split in `map`, or proceed on what is answered. Only his words open a third round. Either verdict writes play_check `verify_target: … complete=<PASS|FAIL> smuggling=<PASS|FAIL>`; PASS also writes `§SIGNOFF: converge-verify passed @ <date>`. Build opens shape with acceptance/contracts to copy and PLAN-agenda. Specification opens narrow review with exact node, artifact identity, owner receipt and this verification receipt; it never opens shape.

## Done when
Both attacks fail to find a hole; signoff exists; build hands evidence to shape, specification to review — or the second FAIL replaces the third round with one owner decision.

## Notes
- State the guarantee honestly: cited openings are structurally excluded; this pass attacks uncited assumptions. Rigorous, not a closed proof.
- Decision-class checklists are cross-node canon in knowledge/; review promotes them.
- No new owner G7 point below the ceiling: verify routes findings and decides nothing; at the ceiling it raises his choice without picking it.
