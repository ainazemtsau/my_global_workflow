# Play: converge

Purpose: drive a build node to the owner-signed WHAT spec shape consumes — disputed terms locked, requirements a cited node-on-paper, every remaining hole named and owned. Contracts ride converge-arch; converge-verify refutes the set before shape.

Reads: TREE.md (node), CHARTER.md (lenses, risk_posture), NOW.md, knowledge/ + the node's history/.
Writes: work/converge-<node>.md, NOW.md (open_calls, decisions), LOG.md. Proposes glossary canon for review/pulse; never writes knowledge/.

Precondition: chosen non-specification node, no bet conflict (G1). Reached via CALL `to: session, play: converge`. A shaped/in-flight node runs as RETROFIT: import settled decisions (step 1), then frame only what remains open.

## Steps

1. **Triage & import** — classify by COST OF REVERSAL; cheap-to-reverse fails safe toward LESS ceremony. First SCAN knowledge/ + history/ for owner-approved decisions: each enters §WHAT `status: answered, source: history/<id>`, born-closed; list the imported ids in the header. Then type: trivial (no disputed term, no sibling, all criteria safe-to-stub) → converge OFF, straight to shape; standard (≥1 term read two ways, OR consumes/produces from a sibling); heavy (model-bearing — wrong stub fatal or defines the product — cross-cutting, or decomposes into subsystems). Write `triage: <type> — converge <OFF|ON> — because <…>` into the header + opening RESULT. A mistyped-low node bounces from shape's Definition-of-Ready.

2. **Define** — seed terms MECHANICALLY from done_when words; only terms read 2+ ways qualify. §GLOSSARY rows `Term | meaning-here | load-bearing properties | competing-readings`. TERM-PROPERTY RULE: a §WHAT line cites a term only for a property in its row; a new property re-opens and re-signs it. Run ONE miner `call:research` over every done_when/lens noun and second reading on disk. Sign disputed terms (G7 — readings ARE the options).

3. **Resolve** — flat §WHAT list, one question/line, tagged `open|answered|deferred`. **`answered` requires a source OUTSIDE this leg — his words, frozen canon, or evidence (shipped code, a run, a measurement). A row this leg reasoned out is `open` and names who owes it: the owner, or PLAN.** Derive from TWO sources: (a) every done_when criterion; (b) every cross-node edge the boundaries name. A committed mechanism is ONE row; its parameters are born at PLAN time. Node-on-paper: every weight-bearing sentence carries an inline citation (`→Wn`, `→GLOSSARY:term[property]`); a sentence citing `open` is itself `open`. FIREWALL: vendor/algorithm/layout/magnitude = HOW → `→ PLAN`; owner-owned design facts + acceptance PROPERTIES → G7; a row carrying both splits, never routed whole; ambiguous defaults to PLAN. Tag acceptance criteria `acceptance` — shape copies them verbatim into the executor done_when, so an `acceptance` row is `answered` or cut, never open. Contested/big → a `call:research` strategic_search child (3–5 refuted options), `deferred → c-research-NNN`. Sign WHAT (G7).

4. **Close & route** — never emit the executor CALL. Emit play_check `imported: [ids]`, `converge_coverage:` (every criterion + edge → a row, `covered_by`, or a named `open`), `open_rows: <n>`, `canon_proposed: [glossary ids]`. `next`: heavy/sibling node → converge-arch; else → converge-verify. Shape runs only after verify passes.

## Done when
Every row is `answered` on an outside source, or `open`/`deferred` with its answerer named. Backward-clean (every weight-bearing line/acceptance/glossary row cited), coverage complete, `§SIGNOFF` for Define and Resolve, set handed to converge-verify. **Open rows never block the close** — they travel to shape as its stub-and-cut agenda; an owner-owed row blocks activation until he answers or defers it in his own words.

## Notes
- Owner decisions are BATCHED per movement/wave, never one-by-one and never silently auto-decided to fit a budget; every genuine owner fork surfaces, however many. Each writes `§SIGNOFF: owner approved <movement> @ <date> — "<owner words>"` (G10).
- HONEST: coverage is mechanical; completeness is settled by BUILDING — this layer only makes the holes visible and named.
