## idea
Веб-ящик для ChatGPT Web: неканоническая папка запросов, куда веб-сторона кладёт
файл, ничего не запуская. Механизм скопирован не по описанию, а с работающего
образца владельца — `C:\projects\concept-lab`, `web-inbox/requests/`: запрос
несёт `schema`, `id`, `origin: chatgpt-web`, `owner_message`, `status: pending`;
кривой вход всё равно сохраняется; оригинал никогда не переписывается;
**сохранение не равно применению** — применяет потом локальный ассистент по
обычным правилам полномочий; непрочитанные запросы ничего не блокируют.
Место — СЛЕДУЮЩАЯ ставка узла 1, сразу после задачи про прогон: разбирать
запросы некому, пока движка нет. Не первая ставка и не узел 5.
