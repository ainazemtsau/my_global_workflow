## idea
Два уточнения к узлу 3 «Проверенная экономичная маршрутизация», которых в его
подписанном тексте сегодня нет. **(а)** API-ключи ограничены дешёвыми моделями:
дорогие берутся только по подписке. Конкретика от него — подписка Alibaba даёт
API-ключ, а Qwen-семейство в узле 3 уже названо прямо. **(б)** Квалификация не
только текстовых моделей: картиночные и 3D-генерирующие тоже прогоняются по
тестам и попадают в tier-лист.
Остальное, что он описал 2026-08-28 — своя проверка моделей под каждый процесс,
tier сложности, рекомендация с его последним словом, перепрогон при выходе новой
модели, экономия токенов — УЖЕ стоит в узле 3 почти построчно. Он переоткрыл
собственный узел, не зная этого. Вносит правку `map`, не эта нога.
## his_words
«Я по API не хочу брать дорогие модели. То есть я в API готов закинуть
какие-нибудь дешевые, там, китайские, либо там вот ChatGPT Luna, например…
подписка на alibaba дает api ключ.»

«Я хочу там, ну вот там вышла модель Kimi, там Kimi 2.6, например, или там 3.0.
Я говорю: хочу ее добавить, но мы, да, прежде чем добавить, хорошо бы по каким-то
тестам прогнать, чтобы понимать, насколько она подходит… Ну вообще еще, наверное,
хорошо какой-нибудь свой иметь, ну, типа tier-лист… потом, может, какие-то еще
там image-модели, 3D-модели генерации, тестировать и так далее.»
