# Комплаенс прогонов гейта — что подтверждено сохранённой уликой, а что нет

Отдельная пометка. Тексты прогонов `run-2026-07-20.md`, `-21.md`, `-22.md` —
замороженная улика и НЕ редактируются. Ничего задним числом в них не дописано.

## Прогоны v1 (20, 21, 22 июля) — комплаенс НЕ ПОДТВЕРЖДЁН

Каждый из трёх прогонов v1 заявлен в своей шапке словами «Комплаенс подтверждён:
агент перечислил прочитанное, вне папки не выходил». Сохранённой уликой это
утверждение не подкреплено.

Факт: блок `ПРОЧИТАНО` отсутствует во всех трёх сохранённых файлах.

```
grep -c 'ПРОЧИТАНО' live/solmax/work/health-gate-runs/run-2026-07-20.md   -> 0
grep -c 'ПРОЧИТАНО' live/solmax/work/health-gate-runs/run-2026-07-21.md   -> 0
grep -c 'ПРОЧИТАНО' live/solmax/work/health-gate-runs/run-2026-07-22.md   -> 0
```

Механизм потери: блок присутствовал в живом возврате агента, но был отброшен при
переносе возврата в сохраняемый файл — сохранялась содержательная часть разбора,
служебный хвост не переносился.

Улика утеряна БЕЗВОЗВРАТНО. Это проверено, а не предположено: файлы возвратов
субагентов той сессии сохранились на диске, но все шесть имеют нулевой размер.

```
wc -c .../a4943d96-bfa9-480e-93b6-f0740a0d546a/tasks/*.output   -> 0 total (6 файлов)
```

Следствие для веса улики: для прогонов v1 нельзя утверждать, что агент не выходил
за пределы своей запечатанной папки. Герметичность прогонов v1 держится только на
конфигурации запуска (отдельный контекст, папка, выданная агенту) и на отсутствии
в их текстах следов посторонних источников — но НЕ на подтверждении самого агента.
Это понижение веса, а не опровержение: признаков выхода за папку в текстах нет.

## Прогоны v2 (21 и 22 июля, перепрогон) — комплаенс ПОДТВЕРЖДЁН присутствием

Для перепрогонов дефект закрыт на уровне механизма, а не аккуратности:

1. Требование блока `ПРОЧИТАНО` вписано в само задание агента как обязательный
   последний блок ответа.
2. Возврат сохраняется вместе с этим блоком.
3. Гейт E проверки утечки (`health-gate-leakcheck-v2.sh`) проверяет ПРИСУТСТВИЕ
   имени каждого файла запечатанной папки внутри блока `ПРОЧИТАНО` возврата.
   Отсутствие блока или недостача любого имени — красный, а не молчаливый зелёный.

Гейт E построен на утверждении о присутствии именно потому, что проверка на
отсутствие уже один раз выродилась в тавтологию — см. `health-gate-leakcheck-v2.sh`,
раздел САМОТЕСТ.
