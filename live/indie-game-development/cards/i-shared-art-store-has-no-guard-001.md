## issue
**ОДИН РЕДАКТОР МОЛЧА СБРОСИЛ РИГ ХОЗЯИНА ДЛЯ ПЯТИ ЧЕКАУТОВ СРАЗУ, И НИЧТО ЭТОГО НЕ ЗАМЕТИЛО.**

**СКЛАД ОДИН НА ВСЕХ, ЧЕРЕЗ NTFS-JUNCTION.** Единственная физическая копия —
`C:\Users\Anton\iCloudDrive\TunnelCrew-Assets\TunnelCrew\Art\Bodies\Sources\Victor\`. Junction на
неё стоит в `win-u1`, `win-u2`, `win-u3`, `win-u4` **и `testrun`**; в `GasCoopGame`, `_dev` и
`win-u5` его нет. Механизм задокументирован (`docs/assets-storage.md`, `tools/assets-link.ps1`) и
сделан намеренно. **Следствие, которое нигде не записано: любой редактор в любом слоте, тронувший
файл склада, меняет его СРАЗУ ВО ВСЕХ ПЯТИ, включая тот, где гоняются тесты.**

**ЧТО СЛУЧИЛОСЬ 2026-08-31.** Мета `Victor_Older_BootFix_AutoHide_03.Fbx.meta` **сброшена в
дефолт**: было 48 758 байт / 1 305 строк / 54 сопоставления кость↔humanName, `animationType: 3`
(Human), `avatarSetup: 1`; стало 2 993 байта / 114 строк / **ноль** костей, `animationType: 2`
(Generic), `avatarSetup: 0`. Стёрто 45 765 байт рига. `CreationTime` файла = 31.08 05:58:41 —
он **создан заново**, а не переписан поверх. По всему складу за сутки тронут ровно ОДИН файл — этот.
Сам FBX не менялся с 25 августа.

**ПОСЛЕДСТВИЕ.** Без рига импортёр не вешает `Animator`, и падает
`BodyReceiverEditModeTests` — «Body prefab has no Animator». Красное воспроизводится в любом слоте:
`win-u1` и `win-u3` получили ОДИН И ТОТ ЖЕ Import Result ID, то есть оба честно импортировали одну
и ту же дефолтную мету. **Испорчен ИСТОЧНИК, а не кэш — сносить `Library` не нужно.**

**ХОРОШАЯ ВЕРСИЯ ЦЕЛА И ЛЕЖИТ В GIT.** Файл БЫЛ отслеживаемым до коммита `6fafb0da` «Keep the heavy
assets out of git». Блоб `5af6cc2455269ddd601d134e38d56d97fc7db78a` — 48 960 байт, тот же
`guid: 32a45d5203b1f7c49a15a6e86e1da92d`, `animationType: 3`, `avatarSetup: 1`, полные
`human`/`skeleton`. **Починка — возврат известных байтов, а не догадка про два поля.**

**ЧЕГО НЕТ И В ЭТОМ СУТЬ УЛИКИ.** У склада нет ни версионирования, ни контрольной суммы, ни
проверки при закрытии ноги. Файл вне git по решению (`.gitignore:233`), и это решение разумно для
84-мегабайтного FBX — но оно оставило **меты**, которые весят килобайты и несут риг, без всякой
защиты. Ничто не заметило пропажу 45 килобайт рига; заметил человек, у которого упал тест.
