## issue
Уронённый предмет может перестать быть услышанным. До ноги A сила приземления была бегущим
МАКСИМУМОМ по всему окну контакта; теперь `_supportForce` пишется только при захвате, а для
продолжающейся опоры захват возможен лишь на первом под-шаге такта. При `_physicsStepsPerTick: 2`
падение, у которого вес приходит на втором под-шаге, отчитывается лёгким первым касанием. Это
доезжает до слуха: `AuthoritativeCargoRoster.SituationOf` кладёт в ситуацию приземления ровно
`contact.SupportForce`, а пороги жёсткие — 3, 15, 35. Перемерено Направлением по байтам `main`.
