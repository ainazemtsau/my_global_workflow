## issue
Порог видимости считается в коде: `HouseholderSightSource.cs:139` — `requiredVisible = sampleCount / 2 + 1`. В ассете названо только число точек тела (`_bodyPointCount 5`), поэтому строгость двигается лишь сменой N, а «видно при 2 из 5» задать нельзя без правки C#.
## review_when
Первая нога, которой законно трогать настройку зрения. Если владелец ни разу не попросит другой строгости при том же числе точек — закрыть как ненужную.
