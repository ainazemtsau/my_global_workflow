## done_when
1. **Обработчик и его условие описываются В ФАЙЛЕ, а не только классом.** Сегодня обработчик — это
   класс `.cs` плюс `.meta` плюс строка в месте композиции; форма годная для конвейера, но не для
   диктовки чат-боту. После задачи выбранный обработчик собирается из авторской строки данных.
2. **ВЕТКА ПОВЕДЕНИЯ описывается данными.** `HouseholderBehaviorBranch` — именованная лента шагов;
   после задачи новая ветка и её шаги приезжают правкой файла, без строки C#.
3. **Кривая строка не молчит.** Неизвестное имя факта, неизвестное умение, дубль имени обработчика,
   отрицательный порог — отвергаются названно, а не глотаются молча. Приём разборщика уже есть:
   `HouseholderProfileLoader` знает два умения и всё прочее отвергает.
4. **Поведение игры не меняется:** те же пять реакций, тот же дефолт. Переезд формы, не содержания.
5. **ОТКАТ** одним коммитом до головы дорожки на момент старта, исполненный настоящим revert.
## note
**СРЕЗАНО ИЗ `t-react-2` ПО РАЗРЕШЁННОЙ ЛИНИИ, а не забыто.** Наряд `c-exec-g-5a7c-react-2-002` прямо назвал: если не помещается в полдня, первым уезжает авторинг данными, и форма обработчика обязана остаться такой, чтобы данные легли на неё ДОБАВЛЕНИЕМ. Исполнитель этот срез сделал и назвал; задача заведена сразу, чтобы срез не потерялся.

**ЭТО ЕГО ГЛАВНОЕ ТРЕБОВАНИЕ, дословно 2026-08-11:** «мне ещё главное требование, чтобы я мог вот это поведение хозяина кастомизировать, желательно через чат-бот — я ему говорю, он JSON кастомизирует… мы программно не задаём никакого хозяина». Пока обработчик остаётся классом, диктовать поведение чат-боту он не может — только принимать написанное ассистентом.

**ЧЕГО ЗДЕСЬ НЕТ:** Odin Inspector и любой редакторский плагин — он назвал их как «потом», и формат данных от них не зависит. Числовая оценка как игровая система, жеребьёвка, долговременная память между запусками, зрение — вне задачи.

**ЗАГОТОВКИ В ФОРМАТЕ УЖЕ ЕСТЬ и не выдуманы:** поле `"when": "always"` в каждом шаге распорядка — место под условие; намеренно пустой `IsKnownPlace` с комментарием про будущую задачу — место под места по имени.
