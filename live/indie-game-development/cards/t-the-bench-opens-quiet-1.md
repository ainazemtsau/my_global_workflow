которая ничего не делает, врёт нажавшему.** Наряд смешал «что загружено при открытии» и «что лежит
на полке» — две разные вещи.

2. **ПУСТОЙ ФАЙЛ НЕ СОЗДАЁТСЯ И НЕ ОСТАЁТСЯ.** На полке только работающие кнопки.

3. **ТРИ ШУМА НЕ ПОТЕРЯНЫ** — лежат своим файлом с прежним заголовком и играют по кнопке.

4. **ТЕСТ ПРО ПОЛКУ ЗЕЛЁНЫЙ БЕЗ ЕДИНОЙ ПРАВКИ В НЁМ.** Правка теста запрещена: тест верен.

5. **ЖИВОЙ ПРОГОН: тихо на открытии, хозяин ходит и делает дела сам; «три шума» по кнопке играют.**

6. **ПРАВКА КОДА — ДВЕ СТРОКИ ЗАГРУЗКИ.** Больше — СТОП. Проверено: имя `default-scenario` не ждёт

7. **ТЕСТЫ ЗЕЛЁНЫЕ ЦЕЛИКОМ.**

**ЧЕГО НЕ ВХОДИТ:** правка теста; кнопки `Emit …` в инспекторе маршрута — вторая половина той же
улики; публикация; любые правки механизма.
