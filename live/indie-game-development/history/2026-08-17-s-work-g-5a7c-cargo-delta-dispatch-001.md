**Механизм.** Тиковое сообщение имеет двух получателей с разными условиями доставки: гости через
`ObserversRpc`, а собственный экран хоста — прямым вызовом под `if (IsClientInitialized)`. Первый
серверный такт наступает раньше, чем поднимается клиентская половина хоста. На этом такте реестр
записывает все предметы как известные ВСЕМ, а получателей ноль. Лежащий предмет не изменится больше
никогда. **Основание прежнего проекта — «каждый наблюдатель получает каждое сообщение» — для хоста
ложно по построению.**

**И единственная страховка ломается одним атрибутом:** `SendTargetRpc` молча возвращается при
`excludeServer && target.IsLocalClient`. У `TargetRpc` умолчание `ExcludeServer = false`, то есть
правильный код — ОТСУТСТВИЕ параметра, а неправильный выглядит единообразно с соседней строкой.

**Разрез переставлен.** Атака доказала, что резать по границе «хост / клиент» нельзя: `Apply`
трактует любой массив как полную перепись мира, поэтому пустой массив дословно значит «уничтожить
все виды» — успех хостовой половины ЕСТЬ её отказ, пустой дом через 33 миллисекунды. Настоящая
граница — **кто имеет право прислать неполный массив**. Отсюда B0 (реестр, тесты, теневой замер,
ноль изменений в поведении) идёт сейчас, B1 (подключение, догон, снятие правила) — одним коммитом
и позже.
