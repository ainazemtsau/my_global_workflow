## boundaries

- Дерево строится вместе с владельцем; frame сознательно не выдумал ни одного ребёнка.
- Первая ставка задана его словом: СВОДКА. Как она выглядит и что показывает — проектирует он сам; сессия карты этого за него не решает.
- Порядок хартии обязателен: сначала чёткость и вид, потом новые возможности, автономность последней.
- Дефект правила сюда не входит — это maintenance-заявка, `live/**` не трогается.
- Кандидаты выше — кандидаты. Ни один не становится `done_when` без слова владельца.
- Ни срока, ни потолка, ни темпа направление не имеет; карта не изобретает их.

3. СВОДКА стоит в дереве ближайшей целью.
4. Каждый кандидат выше либо стал узлом, либо явно отложен с названной причиной.
