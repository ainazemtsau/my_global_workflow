## issue
Число «15% → 17% → 28%», стоящее в хартии датчиком премортема 1 («инструмент съел игру»), зависит от неназванного ключа git и потому фактом не является. Замер 2026-08-13 на дереве `0fb36da6`, те же пути `os/ panel/ osctl.py` против всех коммитов репозитория: при умолчании `git log` — 94/645 = 14,6%, 135/779 = 17,3%, 80/294 = 27,2%; с `--full-history` — 175/645 = 27,1%, 179/779 = 23,0%, 83/294 = 28,2%. Умолчание применяет упрощение истории поверх мерджей, а их 149 в июне, 90 в июле, 3 в августе. То есть РАСТУЩЕГО ТРЕНДА, ради которого число заведено, при втором способе счёта нет вообще. Сверх того август = 27%, а не 28% (старые 28% шли из знаменателя 288 вместо 294). Копий числа в состоянии ТРИ: `CHARTER.md`, `cards/g-one-screen.md` (внутри done_when) и `cards/direction_forecast.md` — чинить надо все три, и хартию правит только `frame`. Пока не пересчитано с названной командой, датчик премортема 1 читать нельзя.
