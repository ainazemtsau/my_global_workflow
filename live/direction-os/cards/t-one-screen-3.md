## goal
Сводка получает свой вид: один экран одного направления с визуальной иерархией, который на
входе даёт мало и просто, а глубину отдаёт по требованию. Свод остаётся работой чата; экран
несёт иерархию, числа, график и проход по цепочке.
## done_when
1. Раздел рисует четыре блока; на входе у каждого не больше пяти строк и число со способом
   счёта рядом.
2. «Подробнее» разворачивает блок, не уводя с экрана.
3. Клик по строке ведёт внутрь: цель — на свою страницу, запись — в свой текст, отчёт ноги — в
   раздел ИСТОРИЯ.
4. Ни одного машинного кода на экране раздела; где имени нет — «без имени», никогда id.
5. Ровно один график — полоса активности за скользящие 30 дней; библиотек не добавлено,
   примитив написан руками. Больше графики на экране нет.
6. Цвет только сигналом, никогда украшением; стиль берётся из `panel/app/style.css` —
   инлайн-стилей и цветов в JS ноль.
7. Экран остаётся ТОЛЬКО ДЛЯ ЧТЕНИЯ: ни одного действия, меняющего состояние.
8. «Целиком» прочитано как ОХВАТ — его слово 2026-08-14: все стороны направления представлены,
   но вход остаётся маленьким. С подписанным «заход даёт мало и просто» экран не спорит.
