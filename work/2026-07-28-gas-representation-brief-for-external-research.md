## ИГРА

Кооперативная игра на 8 игроков (минимум 4), вид от первого лица, Unity + C#.

Мир подземный и почти весь заполнен породой. Игроки САМИ прокапывают тоннели, вскрывают карманы с
газом и платят за это воздухом (счётчик воздуха пополняется только на базе; ушёл далеко — надо
оставить на обратную дорогу). Часть пустот задана автором заранее: карманы с газом, иногда
относительно большие помещения, иногда наполовину засыпанные. То есть забег НЕ начинается с
полностью монолитного массива.

Ключевые свойства мира:

- **Порода не восстанавливается.** Открытый объём монотонно только растёт в течение забега.
  Закопать обратно нельзя.
- **Разрушаемо практически всё**, разница только в трудоёмкости. Неразрушаемых зон, скорее всего,
  не будет.
- **У породы будут свойства** (прочность, внешний вид, возможно зависящий от газа за ней).
  Сейчас их в коде нет вообще.
- **Полная масса газа на карте конечна и известна до сборки.** Бесконечных источников нет.
  Масса может только уменьшаться (стоков сейчас тоже нет, но они рассматриваются на будущее).
- **Возможна критическая ситуация: газ затапливает практически весь выкопанный объём.**

Требования к поведению газа:

- Газ течёт **везде на карте**, а не только рядом с игроками. Схема «симулируем только пузырь
  вокруг игрока» **отвергнута владельцем явно** — не предлагать.
- Замерзать (переставать считаться) газ может **только когда физически устоялся**, а не по
  расстоянию до игрока и не по таймеру.
- **Взаимодействует газ только с игроками** (урон / расход воздуха). Взаимодействие с предметами,
  лутом и прочим вдали НЕ требуется — это единственное упрощение, которое владелец разрешил.
- **Ширина проёма влияет на поток: чем шире рез, тем сильнее пошло.** Вскрытие — это СОБЫТИЕ с
  началом и концом, а не изменение числа.
- Реакции между газами — возможно позже, сейчас нет.

## ЖЁСТКИЕ ОГРАНИЧЕНИЯ

Любое предложение обязано пройти по всем пяти. Нарушение любого = отказ, а не компромисс.

1. **ДЕТЕРМИНИЗМ БИТ В БИТ на всех машинах.** Архитектура — lockstep: по сети идут только вводы
   игроков (надёжно-упорядоченная шина + барьер полноты такта), каждая машина считает мир сама,
   состояние сверяется хешем после каждого такта, первое расхождение — громкий останов.
   **Никакого float на авторитетном пути.** GPU-вычисления для авторитетного состояния исключены.
2. **Закон не читает позицию игрока.** Ничто в движении вещества не считается от того, где стоит
   игрок.
3. **Масса сохраняется точно.** Сколько вышло из кармана — столько в выработке. Стоков нет,
   из ниоткуда не появляется.
4. **Ширина проёма влияет на поток; вскрытие — событие с началом и концом.**
5. **Всё живёт в engine-free C# ядре** без типов Unity, тестируется headless.

## ЧТО УЖЕ ПОСТРОЕНО (проверено чтением исходников)

- **Поклеточный целочисленный перенос массы по граням** с разреженным «активным фронтом»: считаются
  только клетки и грани, где что-то движется. Устоявшийся газ в теории стоит ноль (см. известную
  проблему ниже).
- **Разрешение геометрии и разрешение газа уже разделены.** Газовая клетка обязана быть целым
  кратным геометрической, потолок — до 7× по оси (не более 63 подграней на грань). Проводимость
  грубой газовой грани = **целочисленный СЧЁТ открытых мелких подграней**. То есть «копать мелко,
  газ считать крупно» — работающий механизм, а не идея.
- **До 12 видов газа на клетку**, у каждого свой вес относительно воздуха и коэффициент растекания;
  есть направленный затухающий импульс (ветер / выброс).
- **Стенд детерминизма:** два независимых конца из одного сценария, сверка хеша после каждого такта.
- **Сеть:** FishNet используется только как шина ВВОДА. Мир по сети не рассылается.
  Предсказания и отката нет.

### Чего НЕТ и что переписывается в любом случае

- **Структура мира неизменяема после постройки.** Нет ни одного пути, который добавляет клетку или
  открывает закрытую грань во время игры. Единственный способ изменить форму — построить мир заново
  из нулевого поля, что сбрасывает газ.
- **Порода не существует как данные.** Клетки создаются только внутри объявленных коробок-объёмов;
  порода — это отсутствие клетки. Значит копание — это **добавление клетки**, а не переключение
  флага. Это переписывается, и это база любого варианта.
- Нет чанковой адресации в живом ярусе. Нет свойств породы на клетку.

### Известная проблема, которая может обесценить всю экономику

В нашем же тесте зафиксировано, дословно:

> the original "fixed point ActiveFaces==0" was INFEASIBLE under the frozen integer flow law —
> empirically the field NEVER reaches ActiveFaces==0 for a non-uniform seed; even a single mass unit
> keeps ActiveFaces>=1 forever via the known <=4-unit integer carry-seep "micro-breathing"

То есть поле **никогда не приходит в полный покой**: целочисленные остатки копятся и вечно
перебрасывают единицы туда-обратно. Критерий теста пришлось поменять с «активность = 0» на
«амплитуда колебаний мала».

Почему это может быть смертельно: выработка монотонно растёт весь забег, газ расползается по ней, и
если микродыхание не локально, а расползается вместе с газом, то множество активных клеток дрейфует
к «весь открытый объём». Тогда худший случай — не редкая катастрофа, а нормальный конец каждого
забега. **Это и есть Вопрос 2.**

## ЧТО УЖЕ ПРОВЕРЕНО И ОТВЕРГНУТО — не предлагай это заново

Первый разбор проверил 62 кандидата, 14 прошли адверсариальную проверку, выжил 1 (то, что уже
построено). Отвергнутое, с причиной:

| вариант | на чём упал |
|---|---|
| Групповое выравнивание связного объёма раз в N тактов (SS13/SS14) | масса телепортируется через узкую щель мгновенно ⇒ ломает ограничение 4; «устоялся» решает таймер, а не физика |
| Газ живёт в КОМНАТАХ, а не в клетках (Barotrauma, Stationeers) | внутри комнаты у газа нет положения; у нас весь объём и есть тоннель ⇒ газ мгновенно одинаков по всей длине |
| Пересчёт герметичных объёмов заливкой при каждом изменении (Space Engineers, Empyrion) | связность булева: трещина и снесённая стена — одно событие; вся выработка связна ⇒ одна «комната» на карту |
| Жёсткий предел на размер связного тела жидкости (Factorio 2.0, 250×250) | их дешевизна в том, что внутри сегмента газ мгновенно однороден; предел нечем чинить — породу не вернуть |
| Целое на клетку + потолок активных + «паника»-досаждение (Terraria) | паника либо удаляет массу, либо телепортирует ⇒ ломает ограничение 3 |
| Глубина 0..7 + телепорт под давлением (Dwarf Fortress) | терминатор активности — испарение, то есть сток ⇒ ограничение 3; телепорт убивает вскрытие как событие |
| Грязные прямоугольники + раскрашенные параллельные проходы (Noita) | настоящий ограничитель Noita — окно вокруг игрока (отвергнуто); в 3D прямоугольник на чанк грубее нашего фронта |
| Байт плотности + случайная выборка 1/32 клеток (RimWorld) | фиксированная доля вечно растущего мира платится всегда; диссипация — сток |
| Обновление, независимое от порядка: все читают прошлый такт (структура прохода Factorio) | цена схемы — потолок «не больше ⅙ через грань за такт» ⇒ широкий и узкий рез дают одинаковый первый такт, инверсия ограничения 4 |
| Неконсервативный автомат с фиксированной дальностью (Minecraft) | масса рождается из ниоткуда; дальность зашита числом; дёшево только в чанках вокруг игрока — три запрета сразу |
| Симуляция отдельным нативным модулем (Oxygen Not Included SimDLL) | не C#; возвращает float на авторитетный путь; их сетка не растёт, она выделена заранее |
| Реплей команд разрушения по сети (Teardown) | это транспорт, а не закон газа; у нас он уже есть в более сильной форме |
| Сетевые решатели вентиляции шахт (Hardy Cross, Ventsim, VUMA, CONTAM) | считают установившийся поток по обмеренным выработкам, одно число на ветку, без накопления в узлах; их же руководство пишет, что для малого масштаба не годится |
| Скелет тоннелей (осевой граф из вокселей) | неустойчив: расширение на одну клетку сдвигает ветку и дёргает поток по всей карте; float и частично недетерминированные алгоритмы |

**Установленный факт, который стоит перепроверить независимо:** ни одной вышедшей игры, где
одновременно есть (а) побитово одинаковый счёт на всех машинах, (б) газ по клеткам и (в) мир,
меняющий форму по ходу игры, найти не удалось. Проверено по 14 играм. Если ты найдёшь
контрпример — это самый ценный результат, который ты можешь принести.
